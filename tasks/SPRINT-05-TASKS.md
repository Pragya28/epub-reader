## Day 1 — Theme System

**Concrete plan (2026-08-05, cross-validated against user-specified preferences model):** consolidate into a new `src/features/preferences/` slice — `store/preferences-store.ts` replaces `reader/store/reader-preferences-store.ts` entirely (moved, not duplicated). Store fields split by level:

- **User-level:** `theme` (`system`/`light`/`dark`), `applyThemeToReader` (bool switch — when `true`, the reader follows `theme` and hides its own theme control; when `false`, the reader uses its own `readerTheme`), `readerFont` (shared with reader — see Day 2).
- **Reader-only:** `readerTheme` (used only when `applyThemeToReader` is `false`), `fontScale`, `lineHeight`, `margins`, `paragraphSpacing`.
- `getEffectiveReaderTheme()` selector resolves which theme value the reader actually renders.

1. ✅ **Light/Dark theme tokens** — `src/index.css` now has three cascade layers: base `:root` (light defaults), `@media (prefers-color-scheme: dark) { :root:not(.light):not(.dark) {...} }` (OS fallback), and an explicit `.dark {...}` class block that always wins. Applies across the full app shell, not just the reader iframe. _(done 2026-08-05)_
2. ✅ **Centralized theme system** — `useApplyTheme()` (`features/preferences/hooks/use-apply-theme.ts`) subscribes to `preferencesStore.theme` and toggles `dark`/`light` on `<html>` (`system` removes both). Verified live: toggling theme in Settings flips `document.documentElement.className` and `body` background immediately, and persists across a `/library` navigation. `@custom-variant dark (&:is(.dark *));` (previously-unused shadcn boilerplate) is now load-bearing. _(done 2026-08-05)_
3. ✅ **Apply theme across application UI** — wired once via `useApplyTheme()` at the `app.tsx` root. _(done 2026-08-05)_
4. ✅ **Persist selected theme** — unified store persists as one localStorage entry, key `librune-preferences` (renamed from `reader-preferences`). Verified live via `localStorage.getItem('librune-preferences')`. _(done 2026-08-05)_
5. ✅ **Reader/library consistency** — `getEffectiveReaderTheme()` resolves `applyThemeToReader`; `reader-toolbar.tsx` conditionally renders its own theme control only when `applyThemeToReader` is `false`. Covered by `reader-toolbar.test.tsx` ("hides the theme control when applyThemeToReader is true" / "shows and switches the reader theme when applyThemeToReader is false"). _(done 2026-08-05)_
